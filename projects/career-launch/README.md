# Career Launch

Interview preparation for junior Bay Area roles.

| Asset | Path |
|-------|------|
| Interview playbook (PDF) | `interview-playbook/Bay-Area-Junior-Interview-Playbook.pdf` |
| Playbook source | `interview-playbook/playbook.html` |
| Rebuild | `python3 interview-playbook/build_pdf.py` |

The PDF separates recruiter screens from interviewer loops for junior software engineer, AI engineer, data engineer, and data scientist roles. Answers use the logistics RAG agent, the Home Credit default analysis, and Steady as first-person examples.
